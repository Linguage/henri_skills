# 编辑流程

## 审查权限

- 只报告能够直接对应本 skill 明确条款的问题。
- 每个问题标注“依据：文件名／章节／条款要点”。条款与文本之间的对应关系必须能由另一名审查者复核。
- 不引用模型自己的审美、其他写作手册、未经本 skill 收录的惯例或“通常更好”等主观标准。
- 不把随性、口语、个性化措辞、节奏不齐或非标准文章结构单独判为问题。
- 对个人表达从宽处理；只有明显语病、歧义、指代不清、实际阅读障碍，或事实、证据、伦理等硬条款被触犯时才重点提出。
- 无法确定是否违规时不判错，可以标记为“待作者确认”，并说明对应条款与不确定之处。
- 先按`content-types.md／事实核查强度`确定0至3级。不得用高于主文体的标准审查正文。
- 0级和1级文本中的可疑事实只可列为“可选核对提醒”，不计入问题清单，不影响正常写作，也不自动触发删改、降调或补充来源。
- 可选核对提醒必须与条款问题分开；用户没有要求提醒时，可以完全省略。
- 审查一般问题时指出问题和最小修改范围；确认重复后指出完整重复范围，并明确建议删除整处、合并指定句段或保留指定一处。不得借审查机会提供无关的整段替写。
- 修订时建立“问题—条款—处理动作”一一对应关系。一般问题采用最小替换；重复问题可以删除完整句子、合并指定句段或删除重复段落。任何无法对应已确认问题的改动都必须撤销。
- 句子审查以“前一句—当前句—后一句”为最小窗口。段首、段尾、跨段指代或跨段因果需要扩展到相邻段；单句主干成立不能代替上下文检查。
- 每处修订后必须把修改句放回原位置，依次通读前一句、修改句、后一句和所在段落。检查主语延续、指代、因果、转折、时间顺序、确信程度与重复关系；复读未完成时不得报告修订完成。
- 每次审查先读取`blacklist.md`。黑名单命中属于明确条款问题；禁止依据相似感自行扩大匹配范围。
- 用户要求检查口水话、口头禅、重复词、高频用词、啰唆或口水化时，读取`repetition-watchlist.md`。名单命中只进入“重复观察”；必须同时满足该文件的重复条件和功能冗余判定，才能提出修改。确认后必须给出明确的删除、合并或保留动作。

## 第零轮：载体与文体

检查：

- 这是 Article、Note 还是 Hinbox？
- Article 的主文体是什么？文章主要依靠哪一类证据成立？
- 本文采用0至3级中的哪一级事实核查？
- 是否需要读取一份文体专用规则？
- 混合文体是否真的引入第二套硬约束，还是只共享题材？

先完成文体判断，再进入四轮编辑。不要把六种结构清单同时套在一篇文章上。

## 第一轮：意图与真实

检查：

- 这篇文字真正想考察或传达什么？
- 在当前核查级别下，哪些陈述确有必要区分为事实、记忆、推断或情绪？
- 草稿是否把个人经验推广成对所有人的判断，或在2至3级文本中夸大了支撑核心论点的事实确定性？
- 修改是否增加了事实、动机、时间线或引语？
- 能否识别目标读者？

只有2至3级文本中支撑核心结论的事实出现实质缺口时，才停下来标记。0至1级文本继续正常编辑，存疑内容最多另作可选提醒。

## 第二轮：结构与证据

检查：

- 目标为Article时，是否已经读取`article-structure.md`并按A1至A10检查；目标为Note或Hinbox时，是否避免套用Article结构？
- 能否用一句话写出核心问题？
- 每一节是否服务核心问题？
- 最有力的具体材料是否放在能够承担论点的位置？
- 是否存在重复、岔路或仅为满足模板而出现的章节？
- 是否缺少限制条件、其他解释或必要背景？
- 结尾是否来自文章本身，是否只提高声量？

## 第三轮：句子与节奏

检查：

- 按`sentence-clarity.md`逐项检查S1至S8，是否存在句子成分没有落到明确对象、句尾悬空、搭配不成立、并列关系混乱、指代不清、修饰范围不明、错误逻辑连接或实际阅读障碍？
- 难句中的动作、对象和必要补足语能否辨认？
- 名词化表达是否导致判断没有说完？
- 抽象判断能否指回具体内容？
- 相邻段落是否重复同一结论？
- 朗读时长短句是否自然变化？
- 高风险套语是否真的承担信息？
- 修改是否删掉了有价值的口语和迟疑？
- 是否命中`blacklist.md`中的严格禁用表达？
- 已读取`repetition-watchlist.md`时，是否先区分了全文高频、局部重复、同类叠加和功能冗余？是否保留了承担不确定性、情绪或节奏作用的词？
- 当前句与前后句中的动作承担者是否一致，发生切换时是否已经明确说出新主体？
- 修改后的连接词是否准确表达因果、转折、补充、自我修正或时间推进？

朗读代表段落，或模拟口头表达。修正难以顺畅说出的地方，但不要强迫所有文字口语化。

一般句子问题只修正造成明确问题的最小范围。确认重复后可以删除完整冗余句、合并相邻句或删除重复段落，处理范围只覆盖重复关系。修改后立即执行前后句与所在段落复读，不得等到全文完成后抽查。

“不够顺”“可以更简洁”“略显生硬”“建议优化措辞”不能单独构成问题。语病意见必须标注`sentence-clarity.md`中的S1至S8，并说明具体语法关系或歧义。

## 第四轮：发布检查

检查：

- 按0至3级核查姓名、日期、数字、引语、链接和来源；0至1级不执行逐项外部核对。
- 让标题和摘要准确代表正文，不制造标题党式膨胀。
- 确认小标题对应真实结构，不把连续叙事切得过碎。
- 统一中文标点、中英文混排、Markdown 和 frontmatter。
- 确认内容类型与发布路径。
- 把中文稿标记为唯一源文；需要英文版时再进入翻译流程。

## 审查输出

先给出“载体／主文体／核心证据”的简短判断，再按以下顺序给出问题：

1. `sentence-clarity.md`S1至S8确认的明确语病、歧义和阅读障碍。
2. 核心问题与结构问题。
3. 当前核查级别内成立的事实、归属或认识边界问题。
4. 缺乏支持或过度推广的判断。
5. 能够对应明确条款的重复、抽象和通用语言；`repetition-watchlist.md`命中项单独标为“重复观察”。
6. 节奏、标点和格式。

把文体专用检查发现的问题放入以上优先级，不另起一份重复清单。

每个问题包含：

- 对应的明确条款；
- 位置或短引文；
- 对读者的影响；
- 推荐动作；
- 只有示例能澄清动作时才给出改写示例。

句子问题必须额外标注S1至S8中的问题类型，并说明缺失、错配或歧义发生在哪一组语法关系中。结构问题必须标注A1至A10中的问题类型。无法落入这些条款时，不得用语病或结构问题名义提出。

示例只能覆盖发生问题的最短片段，不提供更具“文采”的整句或整段替换。

无法提供明确条款时，删除该项审查意见。不要为了凑足数量保留弱依据问题。

如需提供“可选核对提醒”，放在问题清单之后，并明确写出“该项不构成违规，不影响正文修订”。不得把提醒混入修改建议。

如需提供“重复观察”，应与黑名单问题分开，写明重复证据、内容作用、判定和明确动作。确认重复后直接写明删除哪一处、合并哪些句段或保留哪一处。仅有全文高频统计时，不提出修改。

除非用户明确要求，不要在审查阶段整篇重写。

## 发布前清单

- [ ] 文章包含作者真正拥有的材料。
- [ ] 已按主文体选择0至3级事实核查，没有把个人记录按学术或报道标准处理。
- [ ] 需要区分的事实、记忆、推断和情绪已在当前核查级别内处理。
- [ ] 目标读者和核心问题足够明确。
- [ ] 发布载体和主文体匹配，使用了正确的证据标准。
- [ ] 具体材料支撑抽象判断。
- [ ] 每一节、每一段都在推进。
- [ ] Article已按`article-structure.md`检查A1至A10；Note与Hinbox没有被强制补齐导言、过渡或结论。
- [ ] 重复结论和空洞过渡已经删除。
- [ ] 句子保留人的节奏，未被统一成整齐的润色腔。
- [ ] 已按`sentence-clarity.md`检查S1至S8；每项语病意见都说明了具体语法关系或歧义。
- [ ] 每个句子都结合前一句和后一句审查；段首、段尾与跨段关系已经扩展到相邻段。
- [ ] 每处修订后已经重新通读修改句、前后句和所在段落，没有新增主语错接、指代歧义、逻辑断裂或无效重复。
- [ ] 已逐项检查`blacklist.md`，新生成内容没有命中黑名单。
- [ ] 用户要求检查重复用词时，已读取`repetition-watchlist.md`；没有把名单命中直接判错，也没有仅凭全文次数提出修改。
- [ ] 每条审查意见均能追溯到已读取的明确条款。
- [ ] 随性和个人化表达没有因模型偏好遭到修改。
- [ ] 每一处修改都对应一条已确认的问题；重复问题可以覆盖完整重复单位，其余内容没有顺手润色或扩大改动范围。
- [ ] 原文中没有问题的用词、句式、段落顺序、语气和节奏保持原样；经条款确认的重复已经删除或合并。
- [ ] 0至1级文本中的存疑信息没有被自动删除、降调、改写或阻断。
- [ ] 没有把中英文之间缺少空格列为问题，新生成文字也未主动插入这类空格。
- [ ] 结尾来自正文并且有意为之。
- [ ] AI 没有增加内容或抹掉作者立场。
- [ ] 中文版本已经独立成立，不依赖未来英文表达才能说清。
