# 学术写作

本模块处理中文论文、研究文章、技术报告和学术章节中可跨项目复用的写作问题。它约束证据关系、论述闭环、术语一致性、章节功能、图表与公式的逻辑职责、结论边界和学术语气。

学校模板、学科专用术语、Word版式、参考文献格式细则和项目日志由目标项目的专用规范负责。项目已有论文审查skill、术语表或格式要求时，先执行项目规则，再用本模块补充通用要求。

## A1｜内容与证据边界

1. 保留原文的研究对象、结论、技术含义、数据、公式、图表编号、引用关系和术语体系。
2. 不新增材料没有支持的事实、数据、引语、因果关系、方法效果、工程建议、适用范围或推广结论。
3. 区分材料事实、研究结果、作者解释和进一步推断。判断强度必须与证据强度一致。
4. 外部事实、数据、引语、概念定义和他人观点应给出可以识别的来源主体及引用。不得用“公开信息”“相关资料”“已有研究”“业内认为”“专家指出”等含混归属代替来源。
5. 使用补充材料时，说明它在论证中的作用，例如提供背景、定义概念、支持判断、构成反例或补充案例。不得只在文末堆放链接。
6. 文章用于公开发布时，不依赖本地路径、附件文件名或读者无法取得的PDF页码。来自本地材料的必要概念应在正文中简要说明；能够公开访问的资料使用公开链接或正式文献标注。
7. 引用不能替代论述。正文需说明来源材料支持了哪一项判断，以及该判断如何进入当前论证。

## A2｜论述闭环

完整论述至少包含四种关系：

1. **问题或对象**：明确文章或章节准备解释、比较、验证或判断什么。
2. **材料或方法**：交代判断依据来自哪些资料、数据、模型、案例或推导。
3. **推理过程**：说明材料与判断之间的关系，避免只排列事实或只宣布结论。
4. **结论与范围**：回答开头提出的问题，并保留材料能够支持的适用条件。

四类关系不要求按照固定段序出现，也不要求每篇文章使用同一种结构。它们只用于检查论述中是否存在无法由正文补足的缺口。

读者只阅读当前成稿，应能理解核心概念、来源归属、推理步骤和结论边界。不得要求读者依赖作者与AI的讨论过程、未发布附件、旧稿或本地文件补足论证。

检查论述闭环时，逐项确认：

- 结论能否指回正文中的材料或推导；
- 引入的案例是否参与后续判断；
- 新概念是否在首次出现处得到简要界定；
- 因果连接是否得到前文支持；
- 结尾是否回答文章原有问题；
- 结尾是否突然增加正文没有论证的新观点。

## A3｜段落与章节职责

1. 一段主要完成一种动作：界定对象、说明背景、描述方法、报告结果、解释原因、比较差异、限定范围或收束结论。
2. 背景、方法、结果、讨论和限制混在同一段时，先调整句序或拆段；不得借机改写没有问题的内容。
3. 同一定义、方法流程、指标含义、数据映射或核心判断只在一个权威位置完整展开。其他位置使用短承接、交叉引用或删除重复内容。
4. 图表已有的数据不在正文逐项抄写。正文说明趋势、差异、条件、原因或对论点的作用。
5. 结果段报告观察和关键数据；讨论段解释原因、意义和边界。两类内容可以相邻，不要换词重复。
6. 段落应推进对象、方法、结果或判断之间的关系，避免写成“本节介绍A、分析B、讨论C”的目录清单。

## A4｜因果与逻辑关系

1. “因此、由此、可见、表明、说明”等词只能连接真实存在的证据与判断关系。
2. 研究动机不能直接充当研究结论；现象不能直接推出作者采用了某种方法。
3. 时间先后、统计相关、机制解释和因果关系应分别表达，不得互相替代。
4. 比较必须说明比较对象、条件和尺度。不同测试条件下的案例不得直接合并成单一能力或效果排序。
5. 反例、个案和局部工况只支持相应范围内的判断。推广时说明新增依据。
6. 必要条件置于结论之前，尽量写出具体对象、输入类别、时间范围或数值范围。

## A5｜术语、符号与概念

1. 同一概念使用一个稳定术语。不得用斜杠、括号、顿号或“也称”并列近义词进行保险式解释。
2. 两个术语含义不同，应直接说明差异；含义相同则选择一个并全文统一。
3. 专门术语、缩写、符号、指标和方法名在首次出现处给出读者需要的界定。后文不反复重写定义。
4. 不创造材料和目标领域中没有依据的新术语。现有术语不足时，标记为待作者确认。
5. 同一变量、符号和单位在全文保持同一含义。公式中出现的符号应有定义，编号公式应在正文中承担作用。
6. 中文正文优先使用已经稳定的中文术语。英文缩写或外文原词只在学科惯例或后文使用需要成立时保留。

## A6｜学术表达

1. 使用清楚、常用、能够直接理解的表达；正式程度不能以晦涩、名词化和长定语堆叠获得。
2. 正文以陈述关系、过程和结果为主。除明确列出研究问题、问卷题项或访谈问题外，慎用“如何……”式提纲和自问自答。
3. 删除写作过程痕迹和空泛提示语，例如“需要说明的是”“需要指出的是”“较稳妥的表述是”“这里应写成”。保留句中的实质内容。
4. “关键、核心、重要、显著、系统、深入”等强化词只有在承担层级区分或得到材料支持时保留。
5. “证明、必然、完全、唯一、无风险”等强判断需要数学证明、规范要求或充分数据支持。证据只能支持趋势、关联或局部结果时，按实际关系表述。
6. 方法、图表、模型和指标承担的动作应符合其实际功能。避免赋予它们“说服、宣告、相信”等人的行为。
7. 条件和限制用于保证科学准确性，不得机械删除。删除重复免责说明时，保留决定结论成立的必要条件。
8. 本skill的严格黑名单、“很＋形容词／评价词”检查、AI模式检查和“爹味”检查继续适用。

## A7｜句子完整性

句子层面继续执行`sentence-clarity.md`。学术文本另加以下保护：

1. 拆分长句时，不删除研究对象、方法来源、数据范围、工况条件、引用归属、适用边界和必要术语。
2. “用于、作为、提供、形成、表明、反映、描述”等动词必须落到明确对象。
3. 并列项应处于同一层级，并能与共用谓语自然搭配。
4. “其、该、上述、前者、后者”等指代存在多个候选对象时，改用最短的明确称谓。
5. 名词化句尾只留下“……的基础”“……的表达”“……的比较”时，补足材料已经支持的实际关系。

## A8｜图表、公式与引用

1. 图表按“正文先引用—图表出现—随后解读”的顺序组织。
2. 图表解读说明关系、趋势、条件、异常或对论点的作用，不复述全部单元格和曲线读数。
3. 图、表、公式和编号均应在正文中被引用并承担明确职责。无正文承接的内容应补足关系或删除。
4. 引用、改绘或整理他人图表时，说明来源关系；不得把他人材料写成作者自行得到的结果。
5. 图表、公式与正文使用同一术语、符号、变量和评价口径。
6. 本模块只检查逻辑职责。编号体例、单位格式、字体字号、分页和渲染效果按项目格式规范处理。

## A9｜常见章节功能

### 章首或长文导语

- 从具体研究问题、理论矛盾、评价需求或前文留下的实质问题进入。
- 说明已有基础、当前缺口和本章回应。
- 可以概括对象、方法和展开关系，不提前公布结果、结论性数据或建议值。
- 避免大段复述上一章、文献综述和目录。

### 节首过渡段

- 交代既有基础、当前问题、工作动机和核心思路。
- 说明本节为什么存在，避免只写“本节将做什么”。
- 不展开参数、图表、计算步骤和结果。
- 引用文献时，明确文献支持的判断，并在段末回到本节的分析对象或方法关系。

### 章节小结或结论

- 回答本章或全文的研究问题，提炼规律、控制关系、方法贡献或适用条件。
- 只保留决定结论的数据，不复述一般数值、方法流程、指标定义和图表内容。
- 结构服从正文的实际逻辑，可以并列，也可以逐步推进。
- 不把局部样本、个别工况或单一案例推广成一般结论。
- 不增加正文没有论证的口号、展望或价值判断。

### 文献综述

- 以研究问题和分歧为组织线索，说明各来源分别支持什么判断。
- 综合方法、证据和结论之间的关系，避免按作者逐篇罗列。
- “研究较多”“受到广泛关注”等数量判断需要可核查依据；缺少依据时直接说明已有研究处理了哪些对象。

## A10｜防御性表述

1. 适用条件直接决定结论是否成立时，在结论前具体说明。
2. 数据来源、模型假设和计算条件在首次需要处说明一次；条件没有变化时不反复提醒。
3. 删除结论后的全要素免责、空泛的“在本文条件下”和为预防质疑添加的否定式自证。
4. 评价结论应给出具体数值、限值、控制要求或正式依据，不使用“满足本文采用的要求”等自我指涉。
5. 展望直接说明后续需要的数据、方法或验证任务，避免先罗列当前研究无法完成的事项。

## A11｜审查与修改顺序

按以下顺序处理，前一层修改可能消除后一层问题：

1. 核对证据归属、结论边界、术语定义和符号一致性等硬伤。
2. 检查问题—材料—推理—结论是否闭合。
3. 检查章节职责、段落功能和重复内容。
4. 检查因果、比较、图表与公式的逻辑职责。
5. 检查句子完整性、学术语气和防御性表述。
6. 最后处理项目规定的机械格式。

审查输出按“证据与来源、论述逻辑、术语符号、段落职责、句子完整性、学术表达、图表公式、章节功能”分类。每项给出位置、最短证据、违反的A条款、读者损失和明确处理动作。

修改仍执行主skill的M1至M3：只处理已确认的问题，保留原有研究结论和作者声音，并在修改后复读前后句与所在段落。项目没有明确要求时，不自动创建修改日志。

## 交付前检查

- [ ] 成稿脱离本地文件、对话记录和未发布附件后仍可独立理解。
- [ ] 外部事实、数据、引语和概念定义具有明确来源。
- [ ] 每项主要结论都能指回正文材料或推导。
- [ ] 研究条件和认识边界没有被删去或后置成免责声明。
- [ ] 同一概念、符号和指标使用稳定名称。
- [ ] 各段、各节和图表承担可辨认且不重复的职责。
- [ ] 结论回答开头的问题，没有新增未论证内容。
- [ ] 新增文本通过黑名单、句子完整性、AI模式、“很＋评价词”和“爹味”复核。
