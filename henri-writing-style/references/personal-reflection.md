# 个人反思与自我审查

## 识别

当文章主要依靠作者真实的行为、选择、困境、情绪和认识变化成立时使用本规则。目标是获得更清楚的自我理解，无需生产普遍人生方法。

## 硬约束

- 只使用作者真实拥有的经历、行为和感受，不补造场景与动机。
- 区分发生了什么、当时的感受、现在的解释和仍然不确定的部分。
- 不从一个私人片段直接概括“现代人”“我们这一代”或所有读者。
- 不把尚未解决的问题改写成已经掌握的方法。
- 默认采用1级事实核查。公共事件只为个人体验提供背景时，不主动搜索核对；存疑内容最多另作可选提醒，不据此修改作者的正常表达。

## 推荐推进

可用“具体困境 → 当时反应 → 现在解释 → 仍未理解之处 → 可能尝试”检查推进，但不要把它变成固定小标题。

- 从一个事件、选择、失败或反复行为开始。
- 检查反思是否改变了理解，避免只把经历换成抽象词重说。
- 保留尴尬、矛盾、自我修正和真实迟疑。
- 行动计划只在真实存在时写出，并让它对应具体问题。
- 允许开放收束，不制造“从今天开始”的假决心。

## 审查问题

- 去掉抽象总结后，还剩下哪些只有作者能提供的材料？
- 文章在哪一点形成了新的理解或更准确的问题？
- 是否把个人经验过度推广成普遍判断？
- 润色是否把有辨识度的口语和犹豫全部删除？

## 常见偏移

- 把焦虑、成长、专注、内耗等词当成解释本身。
- 强行整理成“三个原因、五条方法”。
- 把自我审查写成正确、整齐的个人品牌宣言。
- 用励志结尾掩盖问题仍未解决。
