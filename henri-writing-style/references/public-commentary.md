# 公共议题、人物与事件评论

## 识别

当文章主要依靠公共事实、来源、机制推断和价值判断成立时使用本规则。目标是让读者即使不同意，也能看清作者如何得到判断。

只有公共事实承担核心论点时才使用本规则。个人观赛记录、回忆或反思即使谈到公共人物和事件，仍采用其主文体规则及1级核查，不自动套用本文件。

## 硬约束

- 区分已核实事实、来源转述、个人观察、机制推断和价值判断。
- 让判断强度与证据强度相称；证据有限时降低确定性。
- 明确文章是评论，不用报道口吻掩盖立场。
- 不虚构人物内心、动机、对话和未公开行为。
- 涉及死亡、健康、犯罪、指控、名誉或在世人物时，提高来源、归因与克制标准。
- 让标题、摘要、配图和结尾的确定性不超过正文。
- 事实核查集中于支撑中心判断的关键材料；不把个人语气、预测、讽刺或情绪当作等待证实的报道事实。

## 推荐推进

按需要选择：可核实事实 → 核心争议 → 作者判断 → 支持证据 → 可信的其他解释 → 有限结论。

- 先用一句话写明可争论的中心判断。
- 呈现至少一种可信的其他解释，并说明为何仍保留当前判断。
- 给时间敏感内容标明观察日期；事实变化后更新或加旧文说明。
- 证据支持尖锐判断时保留锋芒，不为表面中立自动软化。

## 审查问题

- 哪一句是文章的中心判断？读者能否将它与事实陈述区分？
- 每个重要判断由什么来源、观察或推理支持？
- 是否使用“显然、注定、早已明白”等措辞跳过证据？
- 是否公平处理了最可信的反方解释？

## 常见偏移

- 用时代、宿命和人性等大词代替具体因果。
- 把文学类比写成事实对应关系。
- 标题比正文更激烈、更确定。
- 为追求完整故事而补写人物心理和因果转折。
