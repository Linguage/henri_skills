# 修改后复核

本文件用于AI参与新写、修改或转换后的最终复核。先完成M3要求的逐处复读，再执行本复核。每项只记录“通过／失败／不适用”；存在失败时，不得直接报告完成。

## 复核边界

- 只修正本次生成或修改引入的问题。
- 原文已有、且不在用户授权范围内的问题不得借复核扩大修改；单独报告并交由作者决定。
- 复核不能以“更自然、更专业、更像人写”代替具体条款，也不能触发整篇重新生成。
- 修正失败项后重新执行相关项目，直至通过，或明确说明为何无法在授权范围内解决。

## V1｜内容完整

- [ ] 没有增加原文不具备的事实、经历、场景、例子、数据、引语、来源、动机、观点或立场。
- [ ] 事实、记忆、推断、情绪和不确定性的强度没有被暗中改变。
- [ ] 时间顺序、因果、转折和人物关系没有被修改成更完整但无依据的故事。

## V2｜作者声音

- [ ] 修改前识别的3至5个本篇声音信号仍能在修订稿中找到文本证据。
- [ ] 有效的口语、幽默、锋芒、自我修正、岔开叙述、停顿和粗糙程度没有因统一风格而消失。
- [ ] 没有把有争议但有依据的判断自动中和成安全、专业或平台化表达。

## V3｜改动范围

- [ ] 每一处改动都能对应用户要求或一条已确认的“问题—条款—处理动作”。
- [ ] 一般问题只修改能够解除问题的最小范围；确认重复只处理已经指认的重复关系。
- [ ] 修改量与实际问题成比例，没有为了显示工作量压缩、重排或重写无问题内容。

## V4｜具体材料

- [ ] 姓名、数字、时间、动作、物品、原话、条件、场景和实际结果没有被抽象概括替换。
- [ ] 摘要、标题和结尾的确定性没有超过正文。
- [ ] 原文缺少具体材料时没有虚构数字、例子或场景补齐。

## V5｜句子与上下文

- [ ] 每处修改均已复读前一句、修改句、后一句和所在段落。
- [ ] 修改没有新增S1至S8中的成分缺失、搭配错误、并列混乱、指代歧义、修饰歧义、逻辑错接或阅读障碍。
- [ ] 删除或合并后没有产生新的重复、主语跳转、时间断裂或确信程度变化。

## V6｜黑名单与观察项

- [ ] 新生成内容没有命中`blacklist.md`。
- [ ] `repetition-watchlist.md`命中项没有仅凭词频被删除，真实不确定性、情绪和节奏仍被保留。
- [ ] 已读取`ai-patterns.md`时，新文本没有引入无作用的模板化模式；原文模式没有被误当作作者身份或AI来源证据。
- [ ] 已读取`paternalistic-tone.md`时，新文本没有引入替读者预判、认知等级、过度推广、训导式第二人称、越权代言或机械总结；“反常识”类标签没有代替材料和判断。

## V7｜输出可追溯

- [ ] 修订稿与改动清单逐项对应，没有未说明的实质变化。
- [ ] AI模式观察、“爹味观察”、重复观察、严格黑名单和可选事实提醒分别报告。
- [ ] 用户只要求检测时，没有擅自输出修订稿、评分或AI作者身份判断。

## 交付条件

V1至V7适用项目全部通过后，才可说明修改后复核已经完成。存在无法处理的失败项时，交付当前可用结果并明确列出失败项、对应条款和所需作者决定，不得用笼统的“已经优化”代替。
