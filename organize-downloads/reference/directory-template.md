# 目录结构参考模板

Downloads 收件区与 Documents 本地暂存库的完整目录结构，含分类说明。

采用“双根目录”模型：`Downloads/` 负责接收、识别、查重和待确认；`Documents/`（或用户指定的位置）保存已经完成分类的本地内容。云端归档库仍是第三个独立角色。向云端“同步、备份、整合、归档”时默认查重后复制并保留本地暂存文件；只有用户明确授权迁移和清空来源时才能移动。

## 完整目录树

```
Downloads/
├── _待处理/                       # 尚未识别、待确认或目标不明确
├── 临时文件/                      # 未完成下载和短期中间状态
└── 待删除/                        # 经确认后集中审核；不直接删除

Documents/
├── 书籍/                          # 已完成分类的本地图书暂存库
│   ├── 数学与物理/                # 数学/物理/力学/几何专著与教材
│   ├── 思想与人文/                # 哲学、传记、心理学、大众科普、宗教、文学
│   ├── AI工程与实践/              # ML/CS 工程经典、实用指南、用户手册
│   ├── 计算机科学与软件工程/       # 计算机科学、编程语言、系统与软件工程
│   ├── 铁路与交通工程/            # 铁路/桥梁/轨道工程专著、教材、设计手册
│   ├── 金融与商业/                # 商业、金融、投资、创业与管理
│   ├── 人物/                      # 按人物归集著作、传记和通信
│   ├── 丛书/                      # 按正式丛书或出版系列归集，优先级仅次于人物
│   ├── 大文件/                    # 主要收纳扫描版，内部按主题再分
│   ├── 杂志/                      # 报纸期刊（按刊名再分子目录）
│   │   └── (按刊名分子目录)/
│   ├── 书籍清单.md                # 所有图书的可查验索引（含中文译名+相对路径链接）
│   ├── inventory.json             # 主数据库（唯一数据源，MD由此生成）
│   └── translations.json          # 中英译名映射（可选）
├── 论文/                          # 论文与学术性内容（按主题分子目录）
│   ├── (主题子目录)/              # 对应原 书籍/ 子目录名（如 AI工程与实践/）
│   └── 专题综述/                  # 长综述、专题论文集和超长预印本
├── 文档/                          # 通用文档及非图书、非论文资料
│   ├── 个人与行政/
│   ├── 受限资料/
│   ├── 技术资料/
│   ├── 报告与白皮书/
│   ├── 整理记录/
│   ├── 文献管理/
│   ├── 文章与访谈/
│   ├── 杂项收容/
│   ├── 档案与合集/
│   └── 课程与演示/
├── 个人档案/                      # 敏感个人信息文档
└── 学位论文/                      # 学位论文及其正式配套资料
```

图片、视频、音频、安装包和数据集不因整理完成而自动进入 `Documents/`。优先复用用户已有的长期目录；目标不明确时留在 `Downloads/_待处理/` 并等待确认，不擅自新建宽泛资料库。

## 书籍/ 主题子目录（权威推荐，迁移时按此组织）

经过实际整理沉淀的标准结构（详见 `phase3-book-thematic.md`）：

| 子目录 | 收录范围 | 典型示例 |
|--------|---------|---------|
| **数学与物理/** | 数学/物理/力学/几何/拓扑的专著、教材、讲义、数学史 | Hatcher 代数拓扑、Strang 线性代数、Needham 可视化微分几何、Kaiser 小波指南、Sandifer Euler 系列 |
| **思想与人文/** | 哲学、传记、心理学、大众科普、宗教、文学、写作指南 | Kahneman、Sivers、爱因斯坦传、康德编著（Cambridge Companion）、Waldrop、Hartnett、圣经 |
| **AI工程与实践/** | ML/CS 工程经典、实用指南、用户手册、技术参考 | Kleppmann DDIA、SICP、Mastering Shell、Gemini Prompting Guide、Reddi MLS、Recht |
| **铁路与交通工程/** | 铁路/桥梁/轨道工程相关的专著、教材、设计手册 | 翟婉明 *车辆-轨道耦合动力学*、桥梁工程手册 |
| **金融与商业/** | 商业、金融、投资、创业、管理及商业人物读物 | 创业管理、市场史、投资与交易实务 |
| **人物/** | **按人名分子目录**，收录该人物的全部著作/传记/通信集 | Grothendieck/、Knuth/、维特根斯坦/、杨振宁/、Kafka/ 等 13 个人物（详见 phase3-book-thematic.md 第七章） |
| **丛书/** | **按正式丛书或出版系列名分子目录**，同一系列不因主题、格式或扫描属性拆散 | 丛书/{丛书名}/ |
| **大文件/** | 主要收纳扫描版，内部沿用主题框架；不按固定文件大小归类 | 大文件/数学与物理/、大文件/思想与人文/、大文件/AI工程与实践/ 等 |
| **杂志/** | 报纸期刊，按刊名再分（Apple/Barron's/Economist/New Yorker/Wired 等 17 种） | — |

**核心原则**：
- `Downloads/` 是收件与处理区，整理完成的文档型内容应离开 Downloads
- `Documents/书籍/` 与云端 `书籍/` 是两个独立书库；前者负责本地暂存，后者负责长期归档
- 从 Documents 向云端备份整合默认复制并分别维护清单；“云端已有”不能作为删除本地文件的依据
- 避免"科技人文与数学"这种过宽目录（原 100+ 文件混杂不利于检索），必须拆为"数学与物理"+"思想与人文"
- 单个主题子目录推荐 30-80 个文件，过多就拆分
- **人物/** 是与主题维度并存的第二维度：当某人物积累了 3+ 本著作（含传记/通信）时，新建 `人物/{人名}/` 并把分散在各主题子目录的著作归位
- `大文件/` 表示扫描属性，不表示固定体积阈值；普通电子版即使较大也不自动迁入
- 归集优先级为：人物 > 丛书 > 用户声明的专门主题 > 扫描属性 > 一般主题，避免把稳定集合拆散
- `杂志/` 下按刊名分子目录；清单脚本递归处理登记类别，但明确排除杂志文件
- `Documents/书籍/` 根目录散落的图书应归位到对应主题子目录

## 论文/ 主题子目录

`论文/` 下的主题子目录**沿用原 `书籍/` 子目录名**（便于追溯来源），如：
- `论文/AI理论与基础模型/`
- `论文/AI Agent与智能体/`
- `论文/AI工程与实践/`
- `论文/科技人文与数学/` 或拆分后的 `论文/数学与物理/`、`论文/思想与人文/`
- `论文/待确认重复/`

**特殊子目录**：
- `论文/专题综述/`：长综述、专题论文集和超长预印本。完整出版的学术专著与教材仍属于图书，不因出版社、难度或页数移入论文目录。

```
└── (其他)                    # 无法归入上述类别的敏感文件
```
